# CoopTask MVP\n\nDemo-ready prototype for CodeCooperatives / SIH 2026.\n\n## Core flow\nCustomer request → verified worker discovery → deterministic FairMatch → worker accepts/starts/completes → cooperative admin visibility.\n\n## FairMatch\n30% skill/experience, 40% distance, 30% workload. Only verified and available workers with the requested skill are eligible.\n\n## Run\n```bash\nnpm install\nnpm run dev\n```\n\nThis prototype uses seeded in-memory demo data intentionally so the pitch does not depend on a remote database. It is separate from the production-oriented CoopTask codebase.\n
